Perguntas Frequentes

Tire suas dúvidas sobre a implantação do Hubitat no seu condomínio

Como funciona a segurança dos dados no banco MySQL?
O Hubitat opera em servidor MySQL exclusivo e dedicado com criptografia de ponta a ponta, isolamento por banco de dados e backups automáticos diários na VPS.
Como os moradores acessam o sistema?
Os moradores podem utilizar o navegador web ou o App PWA instalado diretamente na tela inicial do celular, com suporte a login com 1 toque via Google, Facebook ou Microsoft.
É possível migrar os dados do meu sistema antigo?
Sim, nossa equipe realiza a importação completa de moradores, unidades e veículos sem nenhum custo adicional no plano Premium Pro.
