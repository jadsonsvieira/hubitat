Perguntas Frequentes

Tire suas dúvidas sobre a implantação do Hubitat no seu condomínio

Como funciona o banco de dados e a segurança das informações?
O Hubitat opera em servidor MySQL exclusivo e dedicado com criptografia de ponta a ponta e backups automáticos na VPS.
Como os moradores acessam o sistema?
Os moradores podem utilizar o navegador web ou o aplicativo com suporte a login rápido via Google, Facebook ou Microsoft.
É possível migrar os dados de um sistema antigo?
Sim, nossa equipe oferece suporte para importação de moradores, veículos e cadastros prévios sem custos adicionais no plano Pro.
